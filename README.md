# Oposicions Lloret · Comunicació

Aplicació web estàtica per a estudi personal, en català. **No és una web oficial de l'Ajuntament ni un temari oficial certificat.**

Conté: 12 blocs orientatius de temari, tests autocorregibles, targetes, supòsits pràctics i pla fins al 28/11/2026.

## Publicació
- Vercel: importa aquest directori com a projecte (Framework Preset: Other; Build Command: buit; Output Directory: `.`).
- GitHub Pages: publica els fitxers en una branca i selecciona la carpeta d'arrel com a font a Settings → Pages.
- Local: obre amb un servidor estàtic (`python -m http.server 8000`).

Les dades personals de progrés es desen a `localStorage` del navegador; no existeixen comptes d'usuari ni una base de dades.

**Contingut:** el temari general de 8 temes s'ha extret de bases d'informàtica facilitades per l'usuari, mentre que els blocs de comunicació són provisionals fins a verificar les bases específiques. No pressuposis que el temari coincideix íntegrament amb la convocatòria de comunicació.
